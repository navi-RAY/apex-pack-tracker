# フリーランス応募キット（コピペで使える一式）

> あなたが案件に応募するために必要な文章を全部用意した。
> やることは「登録して貼る」だけ。実績は Reserva と Apex Pack Tracker を使う。

---

## 0. 武器の棚卸し（あなたが既に持っているもの）

| 実績 | 何を証明するか |
|---|---|
| **Reserva**（予約SaaSデモ） | 要件定義→UI→状態管理→ビルドまで一人で完遂できる |
| **Apex Pack Tracker**（PWA・公開済み） | React/TypeScript/Vite/PWA を実運用レベルで書ける |
| GitHub リポジトリ | コードを見せられる＝口だけじゃない証明 |

→ 「ポートフォリオがない」で落ちる初心者の壁を、あなたは既に越えている。

---

## 1. プロフィール文（エージェント登録・クラウドソーシング用）

```
フロントエンドを中心に開発しているエンジニアです。
React / TypeScript / Vite を用いた Web アプリ・PWA の開発を得意としています。

【制作物】
■ Reserva — 個人サロン向け予約管理SaaS（React + TypeScript + Tailwind）
  要件定義からUI設計、状態管理、ビルドまで一人で構築。
  予約フロー・空き枠の自動計算・管理ダッシュボードを実装。

■ Apex Pack Tracker — ゲーム記録用PWA（React + Vite、一般公開・インストール可能）
  オフライン動作・ホーム画面インストールに対応したPWA。

丁寧なコミュニケーションと、動くものを最後まで仕上げる完遂力を大切にしています。
まずは小さな案件から、着実に信頼を積み上げていきたいと考えています。
```

## 3. 応募文テンプレ（案件に応募するとき）

案件の募集文を読んで、[ ]を埋めて送る。

```
はじめまして。ご募集を拝見し応募いたしました。

React / TypeScript でのフロントエンド開発を行っており、
今回の[ 案件内容を一言で ]という点で、お力になれると考えています。

直近では予約管理SaaS「Reserva」を React + TypeScript で個人開発し、
UI設計から状態管理・ビルドまで一貫して担当しました。
公開中のPWA「Apex Pack Tracker」もあり、いずれもコードをGitHubでご覧いただけます。
　▶ [ GitHubのURL ]

[ 案件で求められているスキル ]に対応可能です。
稼働は週[ ○ ]日 / [ ○ ]時間ほど確保できます。

まずは小さな範囲からでも構いませんので、
一度お話しさせていただけますと幸いです。よろしくお願いいたします。
```

## 4. どこに出すか（403で僕が開けなかったので、あなたのブラウザで）

僕は自動アクセスを弾かれて中の一覧を取れなかった。あなたのブラウザなら普通に開ける。
下記に登録 → §3の応募文で応募：

| サイト | 特徴 | URL |
|---|---|---|
| レバテックフリーランス | 高単価・案件数最多 | https://freelance.levtech.jp |
| ITプロパートナーズ | 週2〜/副業に強い | https://itpropartners.com |
| Remogu | フルリモート特化 | https://remogu.jp |
| クラウドワークス | 小さい案件から実績作り | https://crowdworks.jp |
| Wantedly | 直接やり取り・副業歓迎の会社 | https://www.wantedly.com |

> エージェント系（レバテック等）は登録すると担当者が案件を紹介してくれる。
> 「自力で1件ずつ探す」より、登録して紹介を受ける方が現実的に早い。

---

## 5. 最初の1件を取る現実的な順番

1. **今日**: レバテック or ITプロパートナーズに登録（§1のプロフィールを貼る）
2. **今週**: 担当から来た案件 or クラウドワークスの案件に §3 で3件応募
3. **面談**: Reserva の画面を見せながら「これを一人で作った」と話す（最強の武器）
4. **受注**: 小さくてもいいので1件こなす → 実績が2件になる → 次が取りやすくなる

> 単価は最初は気にしない。**「1件納品した」という実績**が、次の高単価案件への鍵。
