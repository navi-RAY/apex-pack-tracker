→ リンクスタンプ: https://navi-ray.github.io/apex-pack-tracker/reserva/

## 4. 投稿後の動き方

1. 投稿にコメントが来たら→「ありがとうございます！DMに詳細お送りしますね」
2. アンケートで「DM/LINEで手動」に投票した人→
   ```
   投票ありがとうございます🙇 実はDM予約の大変さを
   なくすツールを作ってまして、無料モニターを募集してます。
   よければ1分だけデモ見てみてください→（URL）
   ```
3. 「気になる」と来たら→ GO-TO-MARKET.md §3 のトークへ接続

> ポイント: 投稿経由なら「相手から来てくれた」状態なので、
> スパム感ゼロでDMのやり取りを始められる。
